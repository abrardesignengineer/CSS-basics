# CSS Font Properties

A beginner CSS exercise focused on styling text using different font properties.

## What I Practiced

- `font-size` — controlling text size using `px`, `pt`, `em`, and `rem`
- `font-family` — changing typefaces using Google Fonts
- `font-weight` — controlling text thickness and boldness
- CSS ID selectors to target specific HTML elements
- Applying CSS inside an HTML `<style>` element
- Linking Google Fonts to an HTML document

## Built With

- HTML
- CSS
- Google Fonts

## Purpose

Part of my ongoing journey learning HTML and CSS through hands-on exercises.
